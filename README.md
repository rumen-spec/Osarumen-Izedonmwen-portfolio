# Osarumen Izedonmwen's Portfolio

A modern, performant portfolio website built with **Astro**, showcasing professional experience, education, projects, and skills. The site features a clean design with light/dark theme support and a command palette for seamless navigation.

**Live Site:** https://osarumenizedonmwen.com

---

## 🚀 Features

- **Fast & Lightweight** – Built with Astro for optimal performance
- **Dark/Light Mode** – Theme toggle with localStorage persistence
- **Command Palette** – ⌘K/Ctrl+K powered navigation and quick actions
- **Responsive Design** – Mobile-first approach with smooth interactions
- **Smooth Animations** – Reveal animations and cursor glow effects
- **Accessibility** – WCAG compliant with proper ARIA labels and reduced-motion support
- **Modern Styling** – Custom CSS with CSS variables for theming
